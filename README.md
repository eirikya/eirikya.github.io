# eirikya.github.io

Nettsiden til Eirikya Games: https://eirikya.github.io

- `index.html` – forside med spillene og brukerstøtte (support-URL i App Store)
- `personvern.html` – personvernerklæring for Zoo Pop: Animal Merge, norsk og engelsk (`privacy.html` sender videre til den engelske)
- `app-ads.txt` – legges til med linjen fra AdMob (Apper → Vis alle apper → app-ads.txt)
- `assets/` – stil og språkbytte, `img/` – ikon og skjermbilder

Språket velges automatisk etter nettleseren og kan byttes øverst til høyre. `?lang=no` eller `?lang=en` i adressen tvinger et språk.
